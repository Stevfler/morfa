## Порядок внедрения

Каждый этап = отдельный набор задач для субагентов с непересекающимися файлами → QA → отчёт.
Следующий этап начинается, когда QA принял предыдущий.

### Этап 0 — Сборка на всех ОС (фундамент) — ✅ CI готов, ждёт GitHub-репозиторий
Без этого нельзя проверять остальное.
- CI (GitHub Actions) с матрицей `ubuntu-22.04 / macos-latest / windows-latest`: `cargo check` + `bun run build` + `tauri build`.
- Ручной запуск на macOS и Windows, заполнить «?» в таблице.

### Этап 1 — Потеря данных и падения (blockers) — ✅ принято QA 2026-11-02
- `fsops.rs:57` — переименование по регистру разрешать, только если это тот же файл (inode / file id).
- `fsops.rs:63-84` — фолбэк copy+delete: не следовать симлинкам, удалять частичную копию при ошибке, проверять, что цель свободна.
- `fsops.rs:27-38` — валидация имён (разделители, `..`, зарезервированные имена Windows); `create_new` вместо check-then-create.
- `fsinfo.rs:56` — ограничить `max` в `read_text` (1 МБ), читать через `take().read_to_end`.
- `keys.ts:49` — всегда гасить F5 / Ctrl+R / Ctrl+P, чтобы WebView не перезагружался и не открывал печать.

### Этап 2 — Основные операции надёжно — ✅ принято QA 2026-11-02
- `transfer.rs` — работа в `spawn_blocking`, проверка отмены в предскане, частичный результат для undo, симлинки на Windows, проверка «папка в саму себя» без учёта регистра.
- `delete_items`, `stat`, `read_text`, `dir_size` — `spawn_blocking`, ошибки по каждому файлу, отмена `dir_size`.
- Drag & drop нескольких файлов (`FileList.vue:80` — не сбрасывать выделение на mousedown).
- Undo/redo: `pushUndo` для create, redo через повтор операции, а не `restore_trashed`.
- Контекстное меню действует на панель, где кликнули (`PaneMenu.vue:43`).
- Гонка загрузки при быстрой навигации (`navigation.ts:11` — токен запроса).

### Этап 3 — Кроссплатформенные доработки — ✅ принято QA 2026-11-02
- **macOS**: корзина через `NsFileManager`; восстановление → «Показать в Корзине»; `UF_HIDDEN`; Cmd вместо Ctrl, Option для копирования при DnD, Cmd+Backspace = в корзину; канонизация путей (`/private/var`); фильтр томов (`/` + `/Volumes/*`).
- **Windows**: терминал `wt.exe` → `powershell` → `cmd` без мигающего окна; `complete_path` для `C:` и `/`; UNC-пути; watch не блокирует родительские папки; диски без метки.
- **Linux**: дедупликация мест по точке монтирования (btrfs), `$TERMINAL` с аргументами, сбор зомби-процессов.
- Подписи клавиш в меню и тостах через `prettyKeys`.
- Asset-протокол: `requireLiteralLeadingDot: false`, чтобы Quick Look работал в скрытых папках.
